This is a classroom demonstration login only. The username/password check is in browser JavaScript and is NOT secure authentication. Do not store real or confidential financial information. For real user accounts and protected records, connect a backend authentication service (for example Supabase or Firebase) before production use.

To update the existing Netlify site:
1. Extract this ZIP.
2. Open the extracted Business_Expense_Tracker_Netlify folder.
3. Upload the folder contents (index.html, style.css, app.js, README.txt) to the existing Netlify site's manual deploy area, or deploy the folder using the same site's Deploys page.
4. Do not create a new Netlify site if you want to keep the existing URL.
